    \section*{11. Anchor–Deviation Extension (Mean-Reverting Layer)}

    \subsection*{11.1. Motivation}
    To allow the model to express assets with long-horizon anchoring behavior
    while remaining self-contained for simulation and pricing, the anchor must
    be generated by Janiform itself. A fitted model that only stores a future
    anchor path or expects the caller to provide one is not a self-contained
    generative model.

    The goal is therefore to define an endogenous anchor process that is implied
    by the Janiform state under both the physical measure \(P\) and the
    risk-neutral measure \(Q\).

    \subsection*{11.2. Structural State And Core Interval Contribution}

    Let \(X_t^{\mathrm{JF}}\) denote the original Janiform return process:
    \[
        dX_t^{\mathrm{JF}} = d\big(L^+_{A_t^+} - L^-_{A_t^-} + M_t + G_t\big).
    \]

    On the executable interval grid, let \(\Sigma_h\) denote the Janiform
    structural state at boundary \(h\). This includes the Hawkes boundary state
    and any deterministic calendar or known-news state needed to generate the
    next core interval contribution.

    Let \(R_h\) be the Janiform core contribution over interval \(h\), and define
    the physical one-interval log-moment-generating function
    \[
        K_h^P(u \mid \Sigma_h)
        =
        \log \mathbb E^P[e^{u R_h}\mid \Sigma_h].
    \]

    \subsection*{11.3. Endogenous Anchor Under \(P\)}

    Define the physical anchor increment by the conditional mean of the core
    contribution:
    \[
        \mu_h^P(\Sigma_h)
        =
        \partial_u K_h^P(u \mid \Sigma_h)\big|_{u=0}
        =
        \mathbb E^P[R_h \mid \Sigma_h].
    \]

    This increment already bakes in the effects of:
    \begin{itemize}
        \item the expected buy-side NIG contribution,
        \item the expected sell-side NIG contribution,
        \item expected open-window news jumps,
        \item expected closed-window gap jumps,
        \item news-driven Hawkes activity propagation.
    \end{itemize}

    Define the physical anchor recursion
    \[
        A_{h+1}^P = A_h^P + \mu_h^P(\Sigma_h).
    \]

    \subsection*{11.4. Deviation Dynamics Under \(P\)}

    Define the observed-state decomposition
    \[
        X_h = A_h^P + D_h^P.
    \]

    Define the centered core innovation
    \[
        \xi_h^P = R_h - \mu_h^P(\Sigma_h),
        \qquad
        \mathbb E^P[\xi_h^P \mid \Sigma_h] = 0.
    \]

    Let
    \[
        \phi_h = e^{-\kappa \Delta_h},
        \qquad
        \kappa \ge 0.
    \]

    The canonical physical deviation recursion is
    \[
        D_{h+1}^P = \phi_h D_h^P + \xi_h^P
        =
        e^{-\kappa \Delta_h} D_h^P + R_h - \mu_h^P(\Sigma_h).
    \]

    The observed log-price recursion becomes
    \[
        X_{h+1}
        =
        A_{h+1}^P + D_{h+1}^P
        =
        X_h + (\phi_h - 1) D_h^P + R_h.
    \]

    This nests the original model:
    \[
        \kappa = 0 \quad \Rightarrow \quad X_{h+1} = X_h + R_h.
    \]

    \subsection*{11.5. Risk-Neutral Anchor Under \(Q\)}

    Under pricing, the deviation affects the required local tilt. The
    risk-neutral state is therefore
    \[
        Z_h = (\Sigma_h, D_h^Q).
    \]

    Define a local state-dependent tilt \(\theta_h(Z_h)\) and the corresponding
    risk-neutral core transform
    \[
        K_h^Q(u \mid Z_h)
        =
        K_h^P(u + \theta_h(Z_h) \mid \Sigma_h)
        -
        K_h^P(\theta_h(Z_h) \mid \Sigma_h).
    \]

    Define the risk-neutral anchor increment by the first moment of the tilted
    core law:
    \[
        \mu_h^Q(Z_h)
        =
        \partial_u K_h^Q(u \mid Z_h)\big|_{u=0}
        =
        \mathbb E^Q[R_h \mid Z_h].
    \]

    The risk-neutral anchor and deviation recursions are
    \[
        A_{h+1}^Q = A_h^Q + \mu_h^Q(Z_h),
    \]
    \[
        D_{h+1}^Q = \phi_h D_h^Q + R_h - \mu_h^Q(Z_h).
    \]

    \subsection*{11.6. Local Martingale Condition}

    Under \(Q\), the observed return over one interval is
    \[
        \Delta X_h
        =
        \mu_h^Q(Z_h)
        +
        (\phi_h - 1) D_h^Q
        +
        \xi_h^Q,
    \]
    where
    \[
        \xi_h^Q = R_h - \mu_h^Q(Z_h).
    \]

    The local risk-neutral martingale condition is therefore
    \[
        K_h^Q(1 \mid Z_h) + (\phi_h - 1) D_h^Q = (r-q)\Delta_h.
    \]

    This means the risk-neutral anchor is not an externally supplied pricing
    curve. It is generated from the same local tilted transform used by the
    anchored pricing engine.

    \subsection*{11.7. Runtime Materialization}

    The runtime still needs interval-aligned anchor values. The difference is
    that those values are now materialized from the state recursion rather than
    persisted as the top-level fitted-model family.

    For each interval:
    \begin{enumerate}
        \item evaluate \(\mu_h^\star\) from the current state under measure
        \(\star\in\{P,Q\}\),
        \item update \(A_{h+1}^\star = A_h^\star + \mu_h^\star\),
        \item record the interval-aligned anchor values for execution artifacts,
        diagnostics, or exports.
    \end{enumerate}

    \subsection*{11.8. Calibration Strategy}

    To preserve stability and identifiability:
    \begin{enumerate}
        \item calibrate the Janiform core as before,
        \item reconstruct the structural states \(\Sigma_h\) on the calibration
        grid,
        \item compute \(\mu_h^P(\Sigma_h)\) from the fitted core,
        \item build the endogenous physical anchor path recursively,
        \item recover deviations \(D_h^P = X_h - A_h^P\),
        \item estimate \(\kappa\) from the deviation recursion.
    \end{enumerate}

    This staged procedure keeps the anchor endogenous while avoiding a user-
    supplied future anchor path.

    \subsection*{11.9. Identifiability Constraints}

    To minimize parameter competition:
    \begin{itemize}
        \item the anchor must be generated from the Janiform state, not provided
        externally as a free future curve,
        \item \(\kappa\) should correspond to slower time scales than Hawkes decay,
        \item no feedback from \(X_t\) or \(D_t\) into Hawkes intensities, Lévy
        drivers, or news processes is allowed,
        \item no additional jump structure is introduced in the deviation layer.
    \end{itemize}

    \subsection*{11.10. Summary}

    This extension introduces mean reversion as a separate structural layer,
    without modifying the internal Janiform dynamics, while keeping Janiform
    self-contained for both simulation and pricing. It provides:
    \begin{itemize}
        \item a nested generalization of the original model,
        \item an endogenous anchor generated by the model's own state,
        \item mean reversion around that endogenous anchor,
        \item risk-neutral consistency without caller-supplied future anchor paths.
    \end{itemize}
