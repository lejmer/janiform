# Interfaces

These pages describe how you can work with Janiform directly and how other systems can integrate with it. The workflow pages explain what to do. The interface pages explain where to do it: in the CLI, in the Python library, through configuration documents, or through saved run artifacts and event streams.

## Recommended path

1. [Command line interface](cli.md)
2. [Python library](python.md)
3. [Configuration](configuration.md)
4. [Output and automation](output-and-automation.md)

## Pages

| Page                                              | Purpose                                                                                                     |
|---------------------------------------------------|-------------------------------------------------------------------------------------------------------------|
| [Command line interface](cli.md)                  | Running Janiform from a terminal, shell script, scheduler, or CI job with durable saved artifacts.          |
| [Python library](python.md)                       | Embedding Janiform in notebooks, research code, services, or larger applications with typed result objects. |
