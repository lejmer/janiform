\section{Purpose}

Derive the scalar equation that determines the terminal return tilt
\(\theta\).
The activity premia \(\pi_+\) and \(\pi_-\) are pricing-kernel coordinates,
while \(\theta\) is solved so that the discounted ex-dividend terminal price
is a martingale.

\section{Setup}

Write the terminal log return as
\[
    R_{t,T}=d_{t,T}+X_{t,T},
\]
where \(d_{t,T}\) is deterministic conditional on \(\mathcal F_t\) and
\(X_{t,T}\) is the stochastic Janiform terminal component whose cumulant is
\(K_{t,T}\).
Under the normalized density from
\texttt{08\_pricing\_density\_normalization.tex},
\[
    \frac{dQ^{\theta,\pi}}{dP}\bigg|_{\mathcal F_T}
    =
    M_T(\theta,\pi_+,\pi_-).
\]

\section{Result}

\noindent\textbf{Identity.} The martingale tilt \(\theta\) is any admissible
real solution of
\[
    d_{t,T}
    +K_{t,T}(\theta+1,\log\pi_+,\log\pi_-)
    -K_{t,T}(\theta,\log\pi_+,\log\pi_-)
    =
    (r-q)\tau.
\]
The model uses this equation to derive \(\theta\).
It is not an independent free pricing parameter.

\section{Derivation}

The ex-dividend martingale condition is
\[
    \mathbb E^{Q^{\theta,\pi}}\!\left[\frac{S_T}{S_t}\mid\mathcal F_t\right]
    =
    e^{(r-q)\tau}.
\]
Since \(S_T/S_t=e^{R_{t,T}}=e^{d_{t,T}}e^{X_{t,T}}\),
\[
    \mathbb E^{Q^{\theta,\pi}}\!\left[e^{R_{t,T}}\mid\mathcal F_t\right]
    =
    e^{d_{t,T}}
    \mathbb E^{Q^{\theta,\pi}}\!\left[e^{X_{t,T}}\mid\mathcal F_t\right].
\]

Using the density \(M_T\), the stochastic expectation is
\[
    \mathbb E^{Q^{\theta,\pi}}\!\left[e^{X_{t,T}}\mid\mathcal F_t\right]
    =
    \mathbb E^P\!\left[
        e^{X_{t,T}}M_T(\theta,\pi_+,\pi_-)
        \mid\mathcal F_t
    \right].
\]
Substituting the normalized density gives
\[
    \mathbb E^{Q^{\theta,\pi}}\!\left[e^{X_{t,T}}\mid\mathcal F_t\right]
    =
    \frac{
        \mathbb E^P\!\left[
            \exp\!\left(
                (\theta+1)X_{t,T}
                +\log(\pi_+)N_{t,T}^+
                +\log(\pi_-)N_{t,T}^-
            \right)
            \mid\mathcal F_t
        \right]
    }{
        \exp\!\left(K_{t,T}(\theta,\log\pi_+,\log\pi_-)\right)
    }.
\]
By definition of \(K_{t,T}\), this is
\[
    \exp\!\left(
        K_{t,T}(\theta+1,\log\pi_+,\log\pi_-)
        -K_{t,T}(\theta,\log\pi_+,\log\pi_-)
    \right).
\]
Therefore
\[
    \mathbb E^{Q^{\theta,\pi}}\!\left[e^{R_{t,T}}\mid\mathcal F_t\right]
    =
    \exp\!\left(
        d_{t,T}
        +K_{t,T}(\theta+1,\log\pi_+,\log\pi_-)
        -K_{t,T}(\theta,\log\pi_+,\log\pi_-)
    \right).
\]
Equating this to \(e^{(r-q)\tau}\) and taking logs gives
\[
    d_{t,T}
    +K_{t,T}(\theta+1,\log\pi_+,\log\pi_-)
    -K_{t,T}(\theta,\log\pi_+,\log\pi_-)
    =
    (r-q)\tau.
\]
This is the martingale tilt equation solved for \(\theta\).

\section{Domain and validity}

The equation is valid only for real \(\theta\) such that both
\(\theta\) and \(\theta+1\) are inside the terminal cumulant domain for the
given \(\pi_+\) and \(\pi_-\). The density must be normalized, the activity
premia must be strictly positive, and the affine schedule evaluations must
remain finite. Existence and uniqueness are numerical root-solving questions
inside the admissible interval and are not implied by normalization alone.

\section{Consequences}

\begin{itemize}
    \item The martingale tilt is derived from no-arbitrage and the chosen activity premia.
    \item The same denominator cumulant used for density normalization appears in the martingale equation.
    \item The numerator uses a \(+1\) shift because the martingale condition is a first price moment.
    \item Martingale diagnostics should report the residual of this equation, not a fitted \(\theta\) objective.
\end{itemize}
